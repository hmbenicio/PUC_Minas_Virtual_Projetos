# Organizador de Eventos Sociais

`Análise e Desenvolvimento de Sistemas`

`Projeto: Desenvolvimento de Aplicação Web Front-End`

`Eixo 1`

A aplicação desenvolvida é uma ferramenta versátil e abrangente, destinada a atender às necessidades de uma variedade de eventos sociais, desde pequenas festas particulares até eventos empresariais de grande porte. Ao oferecer uma gama de recursos, nossa aplicação visa simplificar os processos complexos e tornar a experiência de organização e coordenação de eventos mais eficiente e prazerosa.

Este é o projeto do **Eixo 1** da coleção de projetos de ADS deste repositório. O código é uma aplicação web front-end em HTML, CSS e JavaScript, com dados locais para demonstração.

## Como executar

Na raiz do repositório completo, instale as dependências uma única vez e inicie o projeto:

```bash
npm install
npm run social
```

O terminal exibirá o endereço local. Para uma consulta rápida sem servidor, abra `codigo-fonte/templates/pagina-inicial/pagina-inicial.html` no navegador.

> Este projeto faz parte do workspace da raiz. As bibliotecas são restauradas pelo `npm install` central e `node_modules` não é versionado. Vídeos de demonstração permanecem fora do Git.
