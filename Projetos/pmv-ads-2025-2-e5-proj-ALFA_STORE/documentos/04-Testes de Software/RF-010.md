# RF-010 — Redirecionamento de compra via Mercado Pago

Encaminhar o cliente do carrinho para o checkout no Mercado Pago.

## Cenário de teste

| Caso | Responsável pela funcionalidade | Responsável pelo teste | Data |
| --- | --- | --- | --- |
| CT-010 — Sucesso | Jonatas de Carvalho Brum | Helbert Miranda | 05/12/2025 |

**Passos**
1. Adicionar produtos ao carrinho.
2. Informar dados de entrega.
3. Selecionar “Finalizar compra”.

**Critérios de êxito**
- Criação da preferência no Mercado Pago.
- Redirecionamento para a página de pagamento com os itens do carrinho.
- Retorno ao site exibindo confirmação de pedido.

**Resultado**
- Aprovado: fluxo de checkout integrado ao Mercado Pago.
