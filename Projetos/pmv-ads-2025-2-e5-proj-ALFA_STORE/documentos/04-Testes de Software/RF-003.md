# RF-003 — Perfis de cliente e admin

Criação de perfis de cliente e elevação/reversão para perfil admin pelo usuário com permissão.

**Passos**
1. Acessar com usuário admin.
2. Abrir a listagem de usuários.
3. Alterar o perfil de um usuário de cliente para admin e, em seguida, reverter para cliente.

**Critérios de êxito**
