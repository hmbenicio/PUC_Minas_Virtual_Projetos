## Dependências

As aplicações Node.js pertencem aos workspaces definidos no `package.json` da raiz. A instalação deve ser feita a partir da raiz do repositório:

```bash
npm install
```

Não versione `node_modules`. Os vídeos de demonstração também permanecem fora do Git; use os links registrados na documentação quando disponíveis.
